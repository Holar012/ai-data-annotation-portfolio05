# LLM Response Evaluation
AI-assisted synthetic demonstration prepared for author review. This is not a client task or a claim of production performance.

## Rubric
- Factual accuracy: all claims must agree with the supplied source.
- Instruction following: exactly two bullet points and no invented facts.
- Completeness: include the closure date and reopening time.
- Unsupported claims: identify facts absent from or contradicted by the source.

PASS/FAIL is a simple practice rubric, not an employer scoring system. Evaluate this benign summarisation task against its supplied source. See evaluation_sample.json for both responses, assessments and the preference rationale.
